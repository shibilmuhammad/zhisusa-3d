# Accommodation Images

Place your accommodation images in this directory with the following filenames:

- `villa.jpg` - Private Villa image
- `cottage.jpg` - Cottage image  
- `tent.jpg` - Eco-luxury Tent image
- `treehouse.jpg` - Tree House image

## Image Requirements

- **Format**: JPEG or PNG
- **Recommended size**: 800x600px or larger (will be automatically optimized by Next.js)
- **Aspect ratio**: Approximately 4:3 or 16:9
- **Style**: Premium, nature-inspired, matching ZHISUSA brand aesthetic

## Unsplash Image Suggestions

You can download high-quality placeholder images from Unsplash:

- Villa: Search "luxury villa nature"
- Cottage: Search "cottage cabin nature"
- Tent: Search "glamping tent luxury"
- Treehouse: Search "treehouse luxury nature"

All images will be automatically optimized by Next.js Image component.
